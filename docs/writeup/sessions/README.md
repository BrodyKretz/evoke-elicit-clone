# Session logs

Raw notes per build session. The point: capture what was *surprising* — the stuff you wouldn't remember when writing the final post.

Format for each session entry:

```markdown
# Session N — <one-line subject>

**Date:**
**Goal:**

## What landed
- bullet of shipped changes

## What surprised me
- the actual interesting stuff. failed approaches, weird LLM output, unexpected API quirks

## What I'd do differently
- next-time notes

## Open questions
- things to think about for the next session
```

Keep them short. The final post will cherry-pick from these — the value is the raw "what actually happened," not polished prose.
